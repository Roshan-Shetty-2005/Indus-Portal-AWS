# Indus Portal – B2B Industrial Material Portal

An AWS-hosted B2B industrial material procurement and catalog portal deployed using **AWS Amplify**.

## 🌐 Live Demo
- **AWS Amplify URL: [https://staging.d3j83oz2wlh38k.amplifyapp.com?utm_source=chatgpt.com]

## 📁 Project Structure
- `index.html` – Main frontend structure and portal interface
- `style.css` – Responsive layout and custom styling
- `script.js` – Interactive catalog, comparison, and RFQ logic
- `AWS_BACKEND_UPDATE.md` – AWS backend architecture and deployment notes

## ☁️ AWS Services Used
- **AWS Amplify** – Frontend hosting and deployment
